## 🛠️ Column Properties and Guidelines

1. **Screen/Function**: The explicit visual screen name or operational backend/frontend system function.
2. **Feature**: The overarching operational feature module containing this item.
3. **Actor**: The primary user role interacting with this function (`Common` denotes system-wide accessibility).
4. **In Charge**: The engineer responsible for design, implementation, and delivery: **Quang**.
5. **Status**: The developmental status of the functional asset:
   * `Done`: Entire backend logic and frontend templates are completed, verified, and integrated.
   * `Doing`: Undergoing incremental optimization or minor UI alignments.
   * `To Do`: Identified roadmap features scheduled for subsequent design phases.
6. **Actual**: The actual iteration where the functional asset was originally introduced.
7. **Updated**: The revision iteration where updates were implemented (marked as `none` if untouched).
8. **Update Details**: Incremental revision histories documenting development nuances.
